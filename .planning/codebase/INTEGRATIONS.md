# INTEGRATIONS

This document lists external systems, APIs, and databases integrated into Wafferly.

## Databases
- **Microsoft SQL Server:** Used as the primary relational database. Accessed via SQLAlchemy and pyodbc. Configured via `$DB_SERVER` and `$DB_NAME`.

## External Services
- **Amazon (Web Scraping):** The core functionality relies on scraping product pages from Amazon to track prices. This relies on BeautifulSoup and Selenium.
- **Email Provider (SMTP):** The application integrates with an SMTP server (specifically Gmail) via `Flask-Mail` to send authentication magic links and price drop notifications.

## Authentication
- **Passwordless Magic Links:** The app uses email-based passwordless authentication. Verification tokens are likely generated by the backend and sent via email, eliminating the need for passwords.
