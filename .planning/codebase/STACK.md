# STACK
This workspace contains a full-stack application (Wafferly) divided into `frontend` and `backend` directories.

## Frontend
- **Framework:** Next.js 16.1.6 (App Router)
- **UI Library:** React 19.2.3
- **Styling:** TailwindCSS 4 with PostCSS & Autoprefixer
- **Animations:** Framer Motion 12, Lenis (Smooth Scrolling), React Responsive Carousel
- **Data Visualization:** Recharts 3.7.0
- **3D Graphics/WebGL:** OGL
- **HTTP Client:** Axios
- **Language:** TypeScript 5

## Backend
- **Framework:** Flask 3.1.3
- **ORM:** SQLAlchemy 2.0.47
- **Database Driver:** pyodbc 5.3.0 (Connecting to Microsoft SQL Server)
- **Web Scraping:** BeautifulSoup4, Selenium, WebDriver Manager
- **Task Scheduling:** APScheduler 3.11.2 (for cron jobs)
- **Email:** Flask-Mail
- **Environment Management:** python-dotenv
- **CORS:** flask-cors
- **Language:** Python 3.x
