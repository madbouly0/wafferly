# STACK RESEARCH
## Recommendations
- **Browser Extension Framework**: Plasmo or native Web Extension API with React + Vite. (Plasmo is recommended for React+Typescript extensions as it simplifies build processes and manifest generation).
- **Frontend (Wishlists)**: Next.js App Router, React Context or Zustand for state management of optimistic UI updates when adding to collections.
- **Backend (Wishlists)**: Flask, SQLAlchemy (Models for Collection, CollectionItem mapping Products to Users).
