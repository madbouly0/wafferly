# RESEARCH SUMMARY
**Domain:** browser extension and wishlist/collection implementations for the Next.js/Flask stack

## Key Findings
**Stack:** Plasmo (React/TypeScript) for the extension. Standard Flask/SQLAlchemy for backend collections. Next.js for dashboard UI.
**Table Stakes:** One-click add from Amazon, visual feedback, CRUD collections, organizing tracked items.
**Watch Out For:** CORS issues between extension and API, securely handling authentication in the extension, and Amazon's brittle DOM structure breaking content scripts.
